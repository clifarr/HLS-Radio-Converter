How to use it

Give each radio the percent-encoded form of a stream URL. For example:

{{ example_radio_url }}

...or, more readably, {{ base }}/stream?url=<url>

There is no station list to configure: the radio is the configuration, and the URL above is all it needs. Optional &name= sets the station name shown on the radio's display, and &br= / &codec= override the output. {% if not ffmpeg_enabled %} With FFmpeg off, &codec= does nothing — there is nothing to re-encode, so the station's own audio is served as it is — and &br= only changes the bitrate reported to the radio, not the audio. {% endif %}
